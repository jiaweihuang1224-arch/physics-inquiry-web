# 自动分类与适合程度

## 先读本题核心，再读现有目录

归类依据是需要解释/求解的物理机制和学习目标，不是题干里某个词。若用户给了现站或源码，只读取当前必要的分类、章节、路由和实验清单，沿用实际 ID 与语言名称；网站已存在的键值优先。未提供站点时可采用以下默认五类，确认报告时一并确认。

|默认ID|中文/English|主要归入|
|---|---|---|
|optics|光学 / Optics|反射、折射、几何成像、透镜/平面镜、光路|
|mechanics|力学 / Mechanics|运动、力、能量、动量、转动、静力与流体|
|waves|波动 / Waves|波形、传播、叠加、驻波、声、干涉和衍射；以波动机制为核心的光也可归这里|
|electromagnetism|电磁学 / Electromagnetism|电荷/电场、电路、磁场、电磁力与感应|
|heat|热学 / Thermal physics|温度、热量、相变、气体与热力学|

章节标题跟随现站已有结构，不假装有课程章号。现站没有章节就建议“光学 / 平面镜”等清晰的小分组，不新增空目录层级。每题一个主要展示位置；相关分类用标签/关联入口，不复制成多个独立实验。分类确定之后还要单独判断题目适不适合网页化。

## 跨领域与无匹配

例如电磁力驱动的运动，如果目标是磁力方向/大小则主类电磁学、标签运动；如果题目只给恒定外力研究运动则可主类力学。双缝光强/相干叠加以波动为主、标签光学；镜子成像以光学为主。解释为何这样选，并给“高/中/低”置信度，置信度是语义判断而非测得概率。

量子、核/粒子、相对论、天体等不能因当前五类缺项就硬塞。报告写“待新增分类建议”，说明推荐名称、与现站的关系及不归现有类的理由；在用户确认报告前不创建目录或分类键。若题目/目标不清造成两个候选无法区分，列最少候选并问目标，而非猜唯一主类。

## 每次报告需要的定位信息

以表格给出主分类（ID及双语名称）、关联标签、理由/置信度、建议章节/小组、实验中英标题和可用 slug。再写现站匹配结果、是否新增卡片/章节/分类、需要改哪些现有页面/清单、是否独立本地交付。只给建议位置，不凭报告说已经写入；实际写入在阶段 B 的当前源码中完成，并检查跳转和分类筛选。

确认后制作时，若现站暂时把实验写死为单个对象，应在已确认的局部范围内改成可扩展清单，而不是覆盖原实验。每个已完成实验保留唯一标识/slug和主分类；分类原本标“陆续加入”时，仅在首个该类实验实际可用后启用入口，并检查目录筛选、卡片、题页/实验路由与返回。

这是由执行助手分析题目完成的分类流程，不是已部署在参考网站里的“上传题目自动入库”后台，也不是专门训练的识别模型。若用户需要浏览器内上传、OCR和服务器自动生成，需要另立明确开发范围，不能说本 Skill 已提供该服务。

## 适用性分层

|判断|适合的呈现|怎样表述|
|---|---|---|
|适合连续实验|有明确状态方程/几何、少量可控变量、直观因果|可做参数实验，先核模型范围再选控件|
|适合作图/解释|受力、光路、图像分析、几何推导|少量构图层、图像与解释联动，不强造时间动画|
|适合有限示意|复杂实际过程但可说明简化假设|报告列出简化及可能误导，不宣称真实过程全模拟|
|当前不宜直接实验化|缺数据、多个不兼容模型、过于开放、依赖无法获得的测量或高成本数值模型|说明缺项，提出最小可行示意/补充问题，保留人工判断|

多小问题可共享一个模型，但各小问仍完整保留；不同机制的小问可分同一作品内的子场景，不强行统一成一个公式。没有跨题型测试集和覆盖率，不称“大多数题目已验证”；可以说“面向多种适合实验化的物理题，每题重新建模和验收”。
