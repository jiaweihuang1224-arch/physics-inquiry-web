# 包内素材与来源身份

本包根据分享者的制作与分享请求整理。只保留通用说明、已采用的生成/组合资产与可运行源码，不包含其知识库、原始教材截图、账号、站点 ID、凭据或 Git 历史。

|相对文件|来源身份|用途|
|---|---|---|
|`assets/home-reference.png`|制作过程中采用的轻玻璃主页参考画面|构图与风格参考，不作为可操作页面|
|`assets/lab-reference.png`|制作过程中采用的本地平面镜实验画面截图|版式、光路/虚像和三角形视觉参考；截图本身不能交互|
|`assets/reference-site/assets/girl.png` 或其实际保留的等价路径|原制作流程生成并采用的独立人物插画|平面镜案例中的人物与对称虚像|
|`assets/reference-site/assets/lab-background.png`|原制作流程采用的背景资产|本地案例页面背景|
|`assets/reference-site/assets/subjects.png`|原制作流程实际生成的分类器材插画组合|主题分类位图，不用作动态几何|
|`assets/reference-site/` 的 HTML/CSS/JS|从已制作的静态网页整理，移除原站身份并改写案例题干|可运行参考、可复用外壳和模型实现|

素材身份描述只说明本包实际包含什么，不代替服务条款或具体权利核实。本包未额外指定开源许可证；没有向接收者传授作者网站的访问权。新题若使用其他教材原图或第三方图库，应按其实际来源与许可决定展示和分发方式，不继承本例资产的身份。
