# 阶段 B 实现经验（按适用条件）

以下规则来自真实实现与测试故障，只在当前题目包含对应功能时应用。示例中的参数、单位和目录结构不自动成为新题的硬编码要求。

| 适用场景 | 实施与核验 |
|---|---|
| 存在多个源码副本、旧 runtime 或多个交付物 | 开始修复前锁定 canonical 源文件与预期输出的绝对路径；用户当前人工编辑版优先。修复后从该源构建，再逐项核对确切的最终 HTML 和所用资产，避免旧 runtime 已修改而用户当前源码仍旧、或源文件与产物不一致。若同时交付项目源文件与独立 HTML，留在同一作品项目中并明确构建输入/输出；允许 src、dist 等子目录，不强制把框架源码与产物平铺。 |
| 原题改编为分享示例或模板 | 对照原题与交付题的完整题干、条件、单位、全部选项及小问，并核对来源身份；脱敏或自编示例应明确标为示例，不能替代用户已采用的原题。 |
| 页面含可选挂载点、主题或学科样式 | 必要挂载点缺失时修正页面/脚本契约，不用静默跳过掩盖缺失功能；确属可选的 mount 才可安全跳过或局部回退。CSS 选择器、颜色变量和 HTML 学科标记（如 `data-subject`）应使用同一约定；启动实际完整页面检查主题是否生效。 |
| 有分段命中区、圆端或动态解释图层 | 在相邻区间的共同边界及透明 hit area 上实际操作，确认命中符合可见几何，不会选中邻段。复位后同时检查计算图层、括号/标签、选择状态和对应可访问状态，不留上一轮残影。 |
| 展示离散时间样本或连续过程 | 只显示数据实际覆盖的时刻；未采样的邻段或未来过程不能被暗示为已观测趋势；模型若另行计算插值或外推，应标为估计/预测，与已记录样本区别显示。采样范围与点数由本题模型决定；曾有一个模型使用 $t=0\ldots14$ 共 15 点（包括起点），不应照搬到其他题。没有实际标尺时不虚构 $\mathrm{m/s}$ 等单位。 |
| 切换实验模式或语言 | 若模式切换代表另一套实验，重置播放、时间和选中对象，避免状态串入新模式。语言切换只改呈现，应保留物理参数、时间、图层、展开内容，并让焦点留在合理的可见控件。若支持 `?lang` 或持久偏好，明确它们与手动切换的初始化、刷新优先级；不要只改文字而留下旧语言返回链接。是否保存偏好按项目设计决定，跨页链接携带当前语言。 |
| 多 HTML 页面提供双语导航，或目录可搜索/筛选 | 用稳定的页面/路由标记（如 `data-page` 或 `data-route`）选择目标，不依赖已被语言切换改写的 `href`。从实际最终 DOM 点击页头、面包屑、页脚各入口，验证中文↔英文可往返；跨页保留当前语言。目录卡片、分类与搜索共用同一分类元数据，按明确类别路由；“加速/减速”等词面不应把同一物理主题误导到其他栏目。 |
| 使用透明 PNG、精灵图或容器相对尺寸 | 在真实合成页面检查透明边缘、脚底/轨道等物理锚点与 SVG 几何是否对齐；核对精灵图 `data-*` 值与脚本映射一致。器材图不烘焙 mockup 标题、控件或动态物理线。若使用 `cqw`，在宽屏与窄屏检查计算后的尺寸及媒体规则级联，避免后续 `vw` 规则覆盖容器尺寸。 |
| 用脚本或 DOM 检查作为验证 | 模型/Node/最小 DOM 检查只证明其覆盖的部分，不代替整页启动、真实点击/拖动或浏览器画面。选择器从最终 DOM 动态读取，避免固定假链接掩盖 href 变化；修复既有故障时，尽可能保留能重现该故障的负向回归检查。 |
| 交付或部署到站点 | 若本地目录由多个 HTML 组成，交付完整相对目录结构和所有目标文件，并实际从目录进入后返回；不能只拷贝单页就声称整站可离线往返。本地 `file://` 入口只用于本地文件；在线返回应指向用户当前站点的同源页面，并保持原站身份和受众。分别记录已验证的模型、整页启动、浏览器操作、桌面/窄屏、控制台与部署状态；未检查的手机或控制台不能被总括为全部通过。 |
